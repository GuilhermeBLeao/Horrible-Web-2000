# 💀 Horrible Web 2000

> **Na nossa empresa, a experiência do usuário é a última das nossas preocupações!**

Bem-vindo ao **Horrible Web 2000**, um projeto de desenvolvimento web que tem como principal objetivo criar uma experiência digital propositalmente desastrosa!

Inspirado na estética dos sites dos anos 1990 e 2000, o projeto reúne cores exageradas, fontes duvidosas, animações inconvenientes, mensagens absurdas e funcionalidades que desafiam qualquer princípio de usabilidade.

Aqui, o caos não é um erro. É uma funcionalidade!

## 🌐 Demonstração

Acesse o projeto publicado:

**[Horrible Web 2000 — Acesse o site](COLOQUE_AQUI_O_LINK_DO_SITE)**

## 🎯 Objetivo do projeto

Desenvolver um site utilizando tecnologias fundamentais do desenvolvimento web, explorando criatividade, interatividade e manipulação de elementos com JavaScript.

O projeto também demonstra, de maneira humorística, como escolhas inadequadas de design e usabilidade podem comprometer a experiência do usuário.

## 🛠️ Tecnologias utilizadas

- **HTML5:** estruturação das páginas e dos conteúdos.
- **CSS3:** estilização, layouts caóticos, efeitos visuais e animações.
- **JavaScript:** interatividade, manipulação do DOM, mensagens aleatórias e comportamentos inesperados.
- **GIFs e imagens:** elementos visuais inspirados na internet clássica.

## 🤡 Funcionalidades

- Navegação entre as páginas do site.
- Botões com comportamentos inesperados.
- Mensagens aleatórias e respostas absurdas.
- Contador fictício de visitantes.
- Formulário de cadastro com validações incomuns.
- Loja virtual com produtos fictícios e carrinho simulado.
- Formulário de contato com respostas aleatórias.
- Animações, efeitos visuais e elementos inspirados nos antigos sites da internet.

## 🧪 Como executar o projeto

Não é necessário instalar dependências ou configurar um servidor backend.

1. Faça o download ou clone este repositório.
2. Abra a pasta do projeto.
3. Execute o arquivo `index.html` no navegador.
4. Prepare-se para uma experiência visual questionável!

Se preferir, utilize a extensão **Live Server** no Visual Studio Code.

## ⚠️ Aviso importante

Este projeto foi desenvolvido com propósitos educacionais e humorísticos.

Os produtos apresentados são fictícios, as compras são simuladas e os formulários não realizam cadastros ou envios reais de informações.

Nenhuma experiência do usuário foi priorizada durante o desenvolvimento.
